# Registros para o blog e patch notes semanais

Toda feature, melhoria ou fix cria/atualiza um arquivo em `entries/<issue>-<resumo>.md`, usando o [modelo central](../../.hawks/vendor/templates/release-note.md) e a [norma editorial Hawks](../../.hawks/vendor/standards/blog-and-release-notes.md). Guardar produto, comportamento, benefício, evidências, disponibilidade e situação editorial. A revisão confere o registro.

Consolidar em `weeks/<inicio>_<fim>-<produto>.md`, por semana de segunda a domingo em America/Sao_Paulo. O blog hawksbi.com.br agrega os posts públicos; a landing mostra o feed do respectivo produto. Registro não dispara publicação e dados internos não entram no feed.
